# ingilizce_calisma-PACEORA-
Paceora, orta (B1) ve orta-üst (B2) seviye İngilizce öğrenenler için geliştirilmiş akıllı bir dil öğrenme platformudur. Uygulama, kullanıcının mevcut yeterliliğini analiz ederek en uygun çalışma materyallerini sunar ve dil gelişimini verimli bir şekilde hızlandırmayı hedefler.
